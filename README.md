# Agent ID 三平台识别与交易界面示例

这是私人 Agent ID 交易台的**公开精简版**，提供 Four.meme、Flap、Gang.fun 的 BSC 合约识别、阶段展示，以及买卖意图界面。页面上的买卖按钮只生成本地演示预览，**不会连接钱包、请求签名或发送链上交易**。真实下单引擎、低延迟执行、钱包集成和个人交易规则不在仓库内。

## 本地运行

需要 Node.js 20 或更新版本。

```sh
npm ci
npm start
```

默认仅监听运行者自己设备的本机 3000 端口。可自行设置 `BSC_RPC_HTTP` 为 BSC 主网 RPC；不要把带密钥的 RPC URL 提交到仓库。这个本机地址与原私人服务无关。

## 包含内容

- `public/`：三平台输入、识别、预算和卖出比例界面。
- `src/recognize.mjs`：只读查询官方登记或对应平台合约，展示可辨认的阶段和报价资产。协议升级后需要重新核验。
- `src/trade-intent.mjs`：纯本地参数校验与演示意图，不构建或广播交易。
- `skill/SKILL.md`：公开版研究工作流，不含个人授权或真实执行命令。

本项目不提供生产交易服务，也未实现多用户钱包隔离。不要将演示服务作为公网交易入口。任何实际交易都需要独立实现钱包授权、合同权限检查、模拟、币安预览、风控、回执和失败对账。
