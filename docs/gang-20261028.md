识别使用注册表 `lookup`，并核对 token 的 `launchpad()`、pad 登记、锁定状态及实际池。注册表新登记的其他 pad 不会被自动加入授权范围，需要单独适配。旧 V2 / Soft / U / S 保留兼容，其中 S 的 `curves` 只有 9 项，不能用 V2 的 10 项布局。

V3 曲线的 WBNB 底池用 `v3BuyBNB` 直接付 BNB，免单独包装及授权；非 BNB 底池仍连续处理报价币兑换、限额授权和买入。曲线卖出直接调用 pad，所得再结算回 BNB。已核实外盘使用 GangRouter 的 `poolBuyBNB` / `poolSellForBNB`，卖出报价包含 handler 的 `previewSellNextBlock` 及税币 swap-back。买入后曲线退款可能是 WBNB，只解包本单回执证明的退款，保留原有 WBNB 余额。

公平打新没有涨价曲线：10,000 整份，每份 50,000 枚。买到总量 1% 是 200 份，实际钱包上限可能只有 50–200 份。目标超过上限或余量时停止，不偷偷少买；BNB 金额模式按预算买整份。未发射时卖出按钮执行 `withdraw`，不需要 ERC-20 授权；按当前退出费报价。发射后走真实池，卖出或转出跌破持有线可能永久失去后续奖励资格，界面保留提醒。

权限与重入检查：交易入口在 pad/router 使用 `nonReentrant`；pad 的路由白名单由 owner 管理，`*For` 绑定 `trader == tx.origin`；router 初始化一次，非任意调用器，不支持替别人花钱。主网 router 的 ProxyAdmin 属于 48 小时时间锁，registry 的升级权限则直接属于平台 Safe，不能声称两者都有时间锁。本项目锁定运行时代码、实现、管理员及 owner，变化时需重新核对，未关闭原有风险/模拟检查。

两个独立公共 RPC 在区块 130258003 / 130258018 对上述部署的代码和代理权限读数一致。测试包括单击直买、非 BNB 连续路径、公平打新、卖回、税后报价、限额及退款保留。另进行主网只读 `eth_call` / 报价核对；这些验证不等于完整安全审计，也不等于已经用真钱逐条成交。
